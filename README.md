An AI-based interactive quantum algorithm learning platform built for SIH25140.

## Features
- Drag-and-drop quantum circuit designer (1, 2, or 3 qubits)
- Auto-generated Qiskit Python code with syntax highlighting
- Preset algorithm demos: Grover's Algorithm, Deutsch-Jozsa
- Measurement histogram and Bloch sphere visualization
- Circuit diagram rendering
- AI tutor chatbot (powered by Google Gemini)
- Quiz module with automated grading

## Tech Stack
- **Frontend:** React, Recharts, react-syntax-highlighter
- **Backend:** Flask (Python), Qiskit Aer
- **AI:** Google Gemini API
